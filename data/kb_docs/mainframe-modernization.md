# Mainframe modernization on AWS: patterns and availability

Plain-English summary of the linked AWS page, written for this demo (paraphrased, not a quotation). Check the source for current detail.

Key points

- AWS Mainframe Modernization describes two patterns: automated refactoring (converting the legacy stack to a Java-based application) and replatforming (keeping the application language and code on a managed runtime, using Rocket Software, formerly Micro Focus).
- Important availability note: the page states that both the self-managed experience and the managed runtime experience are no longer open to new customers. Existing customers can continue to use them.
- For similar capabilities, the page points new customers to vendor-direct offerings and to AWS Transform for mainframe.
- AWS recommends engaging mainframe migration competency partners or AWS Professional Services for these projects.
- A mainframe application is also a standard example of an application to retain until it has been carefully assessed.

Useful when: a customer runs core systems on a mainframe. Check current availability before proposing a specific service.
