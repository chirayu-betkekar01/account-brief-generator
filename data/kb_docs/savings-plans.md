# Savings Plans for compute

Plain-English summary of the linked AWS page, written for this demo (paraphrased, not a quotation). Check the source for current detail.

Key points

- A Savings Plan lowers the price of compute usage in exchange for committing to a steady hourly amount of usage for one or three years.
- AWS states savings of up to 72 percent compared with On-Demand rates; "up to" means it is a ceiling, not a promise.
- Compute Savings Plans apply across instance family, size, operating system, tenancy and Region for Amazon EC2, and also cover AWS Fargate and AWS Lambda.
- The price stays fixed for the term. Payment can be all upfront, partial upfront or no upfront.
- AWS Cost Explorer recommends a commitment level from past usage, and the guide has a page comparing Savings Plans with Reserved Instances.

Useful when: modelling steady-state compute cost; commit only to the usage level a customer is confident to sustain.

Source: https://docs.aws.amazon.com/savingsplans/latest/userguide/what-is-savings-plans.html (checked 2026-10-07)
