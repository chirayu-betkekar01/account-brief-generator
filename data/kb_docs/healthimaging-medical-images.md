# AWS HealthImaging for medical image archives

Plain-English summary of the linked AWS page, written for this demo (paraphrased, not a quotation). Check the source for current detail.

Key points

- AWS HealthImaging is a HIPAA eligible service for storing, analysing and sharing medical images, such as X-ray, CT, MRI and ultrasound, at petabyte scale.
- Use cases include enterprise imaging, long-term archive with subsecond retrieval, and running AI or machine-learning inference over an imaging archive.
- It offers DICOMweb-conformant APIs for interoperability with existing applications, and aims to keep a single authoritative copy of each image in the cloud.
- It automates lifecycle management with intelligent tiering. AWS states it is not a substitute for professional medical judgement: clinical use needs review by trained professionals.

Useful when: healthcare customers with a growing on-premises imaging archive (PACS) and long recovery tests.

Source: https://docs.aws.amazon.com/healthimaging/latest/devguide/what-is.html (checked 2026-10-07)
