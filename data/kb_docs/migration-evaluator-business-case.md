# AWS Migration Evaluator: building a data-driven business case

Plain-English summary of the linked AWS page, written for this demo (paraphrased, not a quotation). Check the source for current detail.

Key points

- Migration Evaluator is a complimentary, guided assessment that helps a customer build a data-driven, directional business case for moving workloads to AWS.
- Its agentless collector is installed on premises with read-only access to VMware, Hyper-V, Windows, Linux, Active Directory and SQL Server, and gathers server profiles (operating system, CPUs, memory), SQL Server metadata, utilisation metrics and network connections.
- Quick Insights, announced in May 2021, is a lighter path that produces a one-page summary of projected AWS cost from measured on-premises provisioning and utilisation.
- The value is replacing guesses about right-sizing with measured utilisation.

Useful when: a customer has no reliable inventory, or wants more accuracy than a first-call estimate. It is the natural next step after discovery.
