# AWS Elemental MediaConvert for video transcoding

Plain-English summary of the linked AWS page, written for this demo (paraphrased, not a quotation). Check the source for current detail.

Key points

- MediaConvert is a file-based video processing service that scales for media libraries of any size.
- Work is organised as jobs (convert an input into outputs), presets (saved encoding settings), job templates and queues (which control parallel processing capacity).
- It supports professional broadcast codecs, HDR, closed captioning, digital rights management and adaptive-bitrate packaging for streaming to many device types.

Useful when: media customers whose transcoding queue backs up at launch events and who want capacity that scales with the workload.

Source: https://docs.aws.amazon.com/mediaconvert/latest/ug/what-is.html (checked 2026-10-07)
