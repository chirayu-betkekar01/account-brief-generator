# Amazon Elastic VMware Service (Amazon EVS)

Plain-English summary of the linked AWS page, written for this demo (paraphrased, not a quotation). Check the source for current detail.

Key points

- Amazon EVS runs a VMware Cloud Foundation environment on Amazon EC2 bare-metal instances inside a customer's Amazon VPC.
- It is designed to let VMware workloads move without changing IP addresses, retraining staff or rewriting operational runbooks, by extending on-premises networks into AWS.
- Customers keep control of their VMware architecture and can self-manage or use an AWS Partner to operate it.
- Once in AWS, workloads sit alongside other AWS services, so modernisation can happen step by step.

Useful when: a customer with a large VMware estate that wants speed and operational continuity before modernising (the relocate strategy).

Source: https://docs.aws.amazon.com/evs/latest/userguide/what-is-evs.html (checked 2026-10-07)
