# PCI DSS and AWS

Plain-English summary of the linked AWS page, written for this demo (paraphrased, not a quotation). Check the source for current detail.

Key points

- AWS holds PCI DSS Level 1 Service Provider status, the highest assessment level, validated by an independent Qualified Security Assessor.
- Customers still manage their own PCI DSS compliance for what they build; AWS does not itself store, transmit or process a customer's cardholder data.
- The Attestation of Compliance and a Responsibility Summary are available through AWS Artifact, and a customer's assessor can rely on the AWS attestation for AWS-deployed environments.
- A list of in-scope services is published on the AWS Services in Scope by Compliance Program page.

Useful when: retail or payments customers with card data, who need to know what AWS covers and what stays with them.

Source: https://aws.amazon.com/compliance/pci-dss-level-1-faqs/ (checked 2026-10-07)
