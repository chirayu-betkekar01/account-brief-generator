# The six pillars of the AWS Well-Architected Framework

Plain-English summary of the linked AWS page, written for this demo (paraphrased, not a quotation). Check the source for current detail.

Key points

- The framework has six pillars: operational excellence, security, reliability, performance efficiency, cost optimization and sustainability.
- It compares building a system to constructing a building: if one foundation is neglected, structural problems can undermine the whole.
- Each pillar has its own guidance, so a review can look at one dimension at a time and weigh trade-offs between them, for example resilience against cost.

Useful when: structuring an architecture review, or giving a customer a shared vocabulary for trade-offs.

Source: https://docs.aws.amazon.com/wellarchitected/latest/framework/the-pillars-of-the-framework.html (checked 2026-10-07)
